# Vaishu Romantic Website — V13

Static GitHub Pages site. No build step required.

## Included
- Responsive desktop/tablet/mobile layout
- 71 local memory photos and thumbnails
- Full-screen memory viewer
- Section-aware hearts, petals, rain, snow, sparkles, kisses and hugs
- Multiple small floating blue robotic-cat / Doraemon-style figures across the full page

## Doraemon asset
The floating figures use `assets/doraemon-float.svg`, a locally bundled original blue robotic-cat illustration sized specifically for the subtle floating effect.

## Deploy
Upload the contents of this folder to the root of a GitHub Pages repository.
